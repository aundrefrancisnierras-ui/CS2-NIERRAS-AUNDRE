# Travel Fare Calculator (V1)

## Description
This program calculates the total travel fare based on distance and number of passengers

### Version 1 - Original code without input validation
- Input: Name, distance, and number of passengers
- Process: Multiplies the fare rate, distance, and number of passengers
- Output: The passenger's name and the total travel fare rounded to two decimal places
- May require input validation

# Travel Fare Calculator (V2)

## Description
The program calculates the total travel fare based on fare rate, distance, and the number of passengers. Input validation is now included.

### Version 2 - Original code with input validation
- Input: Accepts correctly inputted name, distance, and number of passengers
- Process: Checks if input is valid and correct before performing calculations
- Output: The passenger's name and the total travel fare rounded to two decimal places
- Includes input validation
